Ace Base Identity Developer Console

Privacy Policy

How AIDC handles developer identity, application configuration, security events, and operational information.

Last updated October 4, 2026

Information we handle

AIDC is a developer console for configuring Ace Base Identity applications. Depending on how you use the console, we may handle your Ace ID account identity, application configuration, OAuth/OIDC configuration, redirect URIs, credentials metadata, branding settings, authentication activity, security events, and technical request information.

How information is used

We use this information to authenticate developers, operate AIDC, manage applications, verify configuration, provide security controls, maintain audit and authentication activity, troubleshoot failures, and protect the service from abuse.

Authentication and connected identity

AIDC uses Ace ID for developer authentication. AIDC receives the identity information needed to establish your authenticated console session. Application authentication itself is performed by Ace ID according to the configuration of the application.

Security logs and operational data

Security and authentication events may include timestamps, application identifiers, outcomes, request identifiers, and related technical information. These records are used for security, diagnostics, auditing, and service operation.

Data retention

Retention depends on the type of information and its operational purpose. Session data expires according to the service configuration, while application and security records may be retained longer when needed for account operation, security, auditing, or legal obligations.

Your choices

You can review or change application configuration from AIDC and can contact the service team about privacy requests. Some records may need to be retained when required for security, fraud prevention, dispute resolution, or legal compliance.

Changes to this policy

This policy may be updated as AIDC changes. The effective date shown above identifies the current version published on this page.
